[Miniroll](https://miniroll.app?ref=chrishannah.me), the blogroll platform I've been building has come quite a way since it's first inception. You can create and manage blogrolls, embed them on your site, create aggregated rss feeds, fetch your blogrolls via a JSON API, view a global feed of all public blogrolls, and a lot more.

But for a long time, the UI was a very simple, blocky, and overused monospace fonts for every UI element.

I decided that it was time for a revamp, so I first went over a bunch of small details, like rounded borders, accent colours with better contrast, and more readable fonts. After it was in a good state, I worked on a new interface for the platform, which is based around having a sidebar for navigation, and a better use of horizontal space where possible.
